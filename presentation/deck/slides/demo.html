Demo script

  1. 0:00 Home. Pop a bubble, scroll to show the jelly logo, read the one question.
  2. 0:20 Beginner. Pick “Placement interviews (DSA)”, start with C++, show week 1 and its links.
  3. 0:50 Student. Pick SQL: Hard is not offered. Easy, 10 min, answer a few, submit with blanks.
  4. 1:40 Report. Marks, accuracy formula, topic breakdown, open one explanation.
  5. 2:10 Roadmap. Week bubbles, tick a task, take the weekly quiz.
  6. 2:35 Career paths. Filter Core engineering, open VLSI, then Data Analyst: “Load the demo learner” → 43%.
Rehearse this at least three times with a timer. Before going on stage: clear the browser data (or use a fresh profile) so the demo starts clean, close other tabs, turn off notifications, and zoom the browser to 110% so the back row can read it. If Wi-Fi fails, the site still works from a laptop copy: run it locally with npm run dev beforehand, or open the hosted copy you loaded earlier.
