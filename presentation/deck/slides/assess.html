Step 3 · The test engine

Real questions, a fair clock

14

languages, from Python and C++ to Kotlin, Rust and SQL

672

original questions, 16 per language per level

3

levels that test different things, not just harder trivia

  • Every selected language is represented; the rest is split evenly.
  • Question order and option order are fixed per attempt, so a refresh shows exactly what you saw.
  • The deadline is stored as a time, so the clock survives refreshes and background tabs.
  • Auto-submit at zero; a double click on Submit can’t score twice.
Levels mean something: Easy is fundamentals and short code reading, Medium is applying concepts and diagnosing bugs, Hard is edge cases and trade-offs. Example progression in Python: list indexing, then shared references, then how a generator behaves once consumed. Every question has a stable ID, one correct option and an explanation. The reliability points (stored deadline, idempotent submit) are things judges rarely see in hackathon projects, so slow down on them.
