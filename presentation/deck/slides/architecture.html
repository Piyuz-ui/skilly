How it’s built

A fast, private web app with no server to fail

Interface

React 18 + Vite, hash routing, works offline once loaded

Engines

Test engine, scoring, roadmap builder, SkillBridge gap port

Data

Question bank, 23 paths, cached roadmap.sh catalog

Storage

Browser only: validated, versioned, nothing sent anywhere

Three.js bubbles, lazy-loaded

Course catalog loads only on roadmap pages

Static hosting: any free host

Why no backend: privacy (no personal data leaves the device), zero hosting cost, and nothing to go down during a demo. The trade-off is no cross-device sync; accounts are on the roadmap. The roadmap.sh catalog is pulled from its open-source GitHub repo by a script and cached, so the app never depends on a live request.
